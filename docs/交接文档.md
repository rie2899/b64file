## 一、项目是什么

b64file（https://b64file.cn）——Base64 ⇄ 文件的本地转换工具站。核心卖点：**纯浏览器本地处理，没有上传接口**（技术上做不到，不是承诺）。Claude Code 赤陶配色 + 像素终端风视觉，说人话的文案。变现目标：百度 SEO 流量 → 后续广告/增值。

- 代码：`D:\b64file`，git 仓库 `github.com/rie2899/b64file`（**private**），分支 main
- 技术栈：Vite + TypeScript（无框架），74 项 vitest 测试（含 happy-dom DOM 测试）
- 线上：腾讯云轻量服务器 + Docker nginx，IP `82.157.202.200`

## 二、代码地图（按重要度）

## 三、日常更新流程（改动必经）

```bash
cd /d/b64file
# 1. 改代码
pnpm test        # 74 项必须全过
pnpm build       # tsc + prebuild(生成SEO文件) + vite build
# 2. 部署（/data/b64file 属 root，走 ubuntu + 免密 sudo；nginx 即时生效不用重启）
tar -C dist -czf - . | ssh -i ~/.ssh/tencent-ubuntu.pem ubuntu@82.157.202.200 \
  'sudo -n tar -C /data/b64file/html -xzf -'
# 3. 提交推送（WSL 侧 git 无凭证 → 用 Windows 侧 git + 代理）
cmd.exe /c "git -C D:\\b64file -c http.proxy=http://127.0.0.1:7897 push origin main
```

**硬性纪律**：
- **加/减测试后同步两处数字**：`src/static-pages.ts` 里页脚 statusbar 的 `74 tests` + 关于页的 `74 项自动化测试`
- **新页面三件套**：`page-registry.json` 加条目 + `pageData` 加内容 + 复制一个现有 `<id>/index.html` 壳并改 `data-page`
- 文案改动后检查 `tests/base64.test.ts` 的 3 处文案断言（`补上`/`后面`/`用多了`）
