## 1. 知乎（找 3~5 个真实问题回答）

搜这些关键词找问题：「base64 转文件」「base64 保存为 PDF」「接口返回 base64 怎么处理」「base64 图片怎么还原」。

**回答模板**（换成自己的话，按问题的具体情况改）：

> 先说结论：Base64 解码回来就是原始文件，不需要"转换"，需要的是"还原"。
>
> 我上次遇到的问题是接口返回的 JSON 里嵌着两份 PDF 的 Base64（fileContent 字段），直接贴进在线解码工具全报"非法字符"——因为贴的是 JSON 不是纯 Base64。
>
> 三个办法：
> 1. 写几行代码：`Buffer.from(str, 'base64')` 写入文件（Node）或 `base64 -d`（命令行）
> 2. JSON 里单个字段就抠出来解码；多个文件、或者复制不完整的，用工具省事
> 3. 我常用的一个本地工具 b64file.cn，贴整段 JSON 能自动提取里面的 Base64 文件逐个下载，浏览器本地解码不上传，敏感合同发票什么的放心用
>
> 注意：Base64 是编码不是加密，别拿它保护敏感内容。

## 2. CSDN / 掘金技术文（1 篇，长期引流）

**标题**：《接口返回一堆 Base64，前端怎么把文件还原出来》

**结构**（800~1200 字，贴真实代码）：
1. 场景：签署平台/OA 返回 `[{fileName, fileContent}]` JSON，fileContent 是 Base64 的 PDF/Word
2. 纯前端还原方案：`atob` → Uint8Array → Blob → a.download（贴 10 行核心代码）
3. 三个坑：data URL 前缀要剥、URL-safe 变体（- _）要转、复制截断导致 `length % 4 === 1` 必错
4. 文件类型别信扩展名，看魔数（PK=zip/docx/xlsx，%PDF，89 50 4E 47=PNG）
5. 尾部一句："赶时间可以用 b64file.cn，贴 JSON 自动提取，浏览器本地跑"

**发完动作**：文章里链接用 https://b64file.cn/ （首页）+ 场景对应的具体工具页链接。
